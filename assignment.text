Full-Stack Engineering Assessment

Overview
The AI Travel Planner is a web application that allows users to generate a complete travel itinerary using an LLM agent. Users provide travel details such as destination, number of days, interests, and budget. The AI agent generates a day‑by‑day travel plan along with an estimated budget for the trip. Users can also modify the itinerary dynamically.

Preferred Tech Stack 
The preferred tech stack for this assessment is:
Frontend: Next.js + Tailwind CSS
Backend: Node.js + Express
Database: MongoDB
Language: JavaScript or TypeScript

Application Overview
Build a multi-user trip planner where:
Users can register and log in
Each user has a personalized dashboard
Accept travel details from the user
Generate a structured itinerary using an LLM
Estimate the trip budget
Allow itinerary modification
Suggest hotels for the destination
The application must support multiple users with strict data isolation.


Core Requirements
1. Authentication & Authorization
Secure user authentication
Authorization enforced across the application
Protected access to user-specific features
Users must not be able to access or modify other users’ data


2. Trip Input Form
     Users provide:
Destination
Number of days
Budget type (Low / Medium / High)
Interests (Food, Culture, Adventure, Shopping, etc.)


3. AI Itinerary Generator
The LLM agent generates a day‑by‑day itinerary based on user inputs.
Example Output:
Day 1
Visit Senso‑ji Temple
Explore Asakusa street food

Day 2
Tokyo Skytree
Akihabara shopping


4. Budget Estimation 
The AI agent estimates the overall travel cost based on:
Destination
Number of days
Budget preference
Typical travel costs
Example:
Estimated Budget:
Flights: $400
Accommodation: $300
Food: $150
Activities: $100
Total Estimated Budget: $950


5. Editable Itinerary
Users should be able to:
Remove an activity
Add a new activity
Regenerate a specific day
Example request:
"Regenerate Day 3 with more outdoor activities"


6. Bonus Feature
Hotel Suggestions
The AI agent suggests hotels based on:
Destination
Budget
Popular traveler ratings
Example:
Recommended Hotels:
• Hotel Sakura Tokyo – Budget Friendly
• Shinjuku Grand Hotel – Mid Range
• Tokyo Imperial Palace Hotel – Luxury
